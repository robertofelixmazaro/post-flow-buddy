# Agenda Plus — brand assets

The official Agenda Plus logo (calendar with "+", purple/blue/cyan gradient,
tagline "Plataforma de agendamento — Agendamento inteligente") was NOT found
among the project files or uploads. Do not replace it with an invented logo.

When the file is provided:
1. Upload it via lovable-assets and save the pointer as `logo.png.asset.json` here.
2. Use it in Sidebar and Auth headers (currently text "Agenda Plus").
3. Derive `public/favicon.png` (64x64, padded) from the isolated symbol.
4. Add og:image / twitter:image in index.html only with an absolute public https URL.
